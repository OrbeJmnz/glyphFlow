Empezando

Iconos de Lucide animados sobre Web Animations API nativa. Cero dependencias de animación en runtime — ni @angular/animations, ni Motion, ni GSAP.

Instalar

npm i glyphflow

Angular 20, 21 o 22 (peerDependencies: >=20.0.0 <23.0.0). La única dependencia real es tslib. Licencia MIT.

Tu primer icono

El componente es standalone: se importa donde se usa, sin módulo intermedio. El icono se pasa como valor, con un import nombrado. 

import { Component } from '@angular/core';
import { MaxIconComponent, bellIcon } from 'glyphflow';

@Component({
  selector: 'app-aviso',
  imports: [MaxIconComponent],
  template: '<max-icon [iconDef]="bell" [size]="24" label="Notificaciones" />',
})
export class Aviso {
  protected readonly bell = bellIcon;
}

El selector es max-icon, no glyphflow-icon: el prefijo no se ata al nombre del paquete, mismo patrón que mat-button o p-button.

Por qué [iconDef] y no name=

Porque es la ruta que de verdad hace tree-shaking. Los números salen del presupuesto que corre en CI en cada commit, no de una promesa:

Qué importas Bundle (gzip)
Solo el componente, sin ningún icono 3.74 KB
Componente + 1 icono por import nombrado 4.09 KB
name= con el registro completo 94.48 KB

Un icono cuesta ese icono. Buscar por nombre en tiempo de ejecución obliga al bundler a conservar los 1767, porque no puede saber cuál vas a pedir.

Si aun así quieres name=

Existe, y es opt-in a propósito: sin registrar el catálogo, name="bell" no pinta nada y no truena — mismo contrato que un nombre desconocido. 

import { provideIconCatalog, ANIMATED_ICONS } from 'glyphflow';

bootstrapApplication(App, {
  providers: [provideIconCatalog(ANIMATED_ICONS)],
});

Ese provideIconCatalog(ANIMATED_ICONS) es justo lo que trae los 94 KB. Úsalo cuando el nombre del icono sea un dato (viene de una API, de una config), no cuando lo escribes tú en la plantilla.

Cuándo se anima

trigger Qué hace
group Dibuja al montarse y se anima con el hover del contenedor .group más cercano — el mismo que gobierna group-hover: de Tailwind. Si no hay ninguno, escucha al propio icono.
hover Al entrar el puntero.
tap Al hacer click.
view Al entrar al viewport. Con viewOnce decides si una vez o cada reentrada.
auto En cuanto monta.
manual Nunca solo: lo disparas tú llamando play() sobre la instancia.

Velocidad global

Un solo multiplicador para todas las duraciones calculadas — coreografías y transiciones de morph por igual. 1 es sin cambio; sin proveer nada, el comportamiento queda intacto. 

import { provideMaxIcons } from 'glyphflow';

providers: [provideMaxIcons({ durationScale: 0.8 })]

Los chips de velocidad de la barra superior de este sitio son exactamente eso, movidos en vivo. Aplican desde la siguiente reproducción: lo que ya está corriendo conserva la duración que el navegador ya recibió.

Morph entre dos iconos

Vive en un entry point aparte, glyphflow/morph, para que quien solo quiera iconos animados no pague la matemática de interpolación de formas. 

import { MaxIconMorphComponent } from 'glyphflow/morph';

// El binding ES el estado: cambiar [icon] dispara la transición desde el valor anterior.
// <max-icon-morph [icon]="actual()" [size]="32" label="Estado" />

El primer valor se pinta estático — morphear "desde nada" no existe. Ahí cae también el SSR y cualquier navegador sin WAAPI: se ve el icono, no se anima.
