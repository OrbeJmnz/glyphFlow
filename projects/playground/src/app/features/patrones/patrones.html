Patrones

La cuadrícula de iconos enseña qué hay. Esto enseña para qué sirve: controles que de verdad hacen lo que dicen — el de copiar copia, el de tema cambia colores, el de enviar tiene sus tres estados. El código de cada uno está al lado.

Copiar al portapapeles

El caso donde el morph gana claro: copy → check confirma sin mover el layout ni meter un toast. El botón de arriba copia de verdad — pruébalo y pega.

Si el writeText falla (sin permiso, sin foco, sitio en http) el estado no cambia: el icono se queda en copy en vez de mentir con una palomita. 

protected readonly copiado = signal(false);
protected readonly icono = computed(() => (this.copiado() ? checkIcon : copyIcon));

async copiar() {
  try { await navigator.clipboard.writeText(texto); } catch { return; }
  this.copiado.set(true);
  setTimeout(() => this.copiado.set(false), 1600);
}

<max-icon-morph [icon]="icono()" [size]="18" spring="bouncy" />

Cambio de tema

moon ↔ sun. El icono hereda el color del texto (stroke="currentColor"), así que el tema no necesita tocarlo: cambia el color del contenedor y el icono va detrás.

Aquí el tema aplica solo a este panel, para que se vea el patrón aislado. El de verdad está en el header, con el mismo morph: escribe data-tema en <html>, recuerda tu elección y descubre el tema nuevo con un círculo que crece desde el propio botón. 

protected readonly claro = signal(false);
protected readonly icono = computed(() => (this.claro() ? sunIcon : moonIcon));

<button [attr.aria-label]="claro() ? 'Tema oscuro' : 'Tema claro'">
  <max-icon-morph [icon]="icono()" [size]="20" />
</button>

Acción con tres estados

Reposo → enviando → enviado, y de regreso. send → circle-check por morph; el spinner es un <max-icon> curado en loop.

Mezclarlos no es descuido: un morph tiene principio y fin, y "cargando" no sabe cuándo termina. Para un estado de duración desconocida se necesita una animación que cicle, que es exactamente lo que el motor de coreografía ya hace. 

@if (estado() === 'enviando') {
  <max-icon [iconDef]="loaderCircleIcon" trigger="auto" [loop]="true" />
} @else {
  <max-icon-morph [icon]="estado() === 'enviado' ? circleCheckIcon : sendIcon" />
}

Reacción

Aquí no hay morph: la forma no cambia, solo el gesto. trigger="tap" reproduce la coreografía curada del corazón en cada click, y el color lo pone el botón.

La regla para elegir motor: si el icono cambia de forma, morph; si el mismo icono reacciona, coreografía. Meter morph aquí sería pagar la interpolación de dos figuras idénticas. 

<button [attr.aria-pressed]="meGusta()" (click)="alternar()">
  <max-icon [iconDef]="heartIcon" [size]="18" trigger="tap" />
  {{ votos() }}
</button>
