Los iconos

Además de lo anterior, glyphflow exporta un const por icono con sufijo Icon — bellIcon, trash2Icon, circleCheckIcon. Esos son la ruta tree-shakeable, y por eso no se listan uno por uno: son ~1767 y el catálogo navegable está en la página de iconos.

El nombre del const es el del icono en camelCase más Icon: trash-2 → trash2Icon, circle-check → circleCheckIcon. El panel de detalle de cada icono te da el snippet ya armado.
