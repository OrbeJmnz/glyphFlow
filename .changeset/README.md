# Changesets

Antes de un PR que cambie `glyphflow` de forma publicable, corre `npx changeset` y describe el
cambio. Política de versionado (ver el plan del proyecto): icono/animación nueva = minor, ajuste de
timing en una coreografía existente = minor/patch, renombrar/quitar un icono o cambiar la forma de
los inputs/tipos exportados = major.

Docs: https://github.com/changesets/changesets
